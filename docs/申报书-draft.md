## 项目名称

MoonCrawl —— 纯 MoonBit 的声明式网页采集框架

## GitHub 仓库

https://github.com/guangting0905/mooncrawl （待创建后回填）

## 一句话介绍

把「抓网页 → 提数据 → 出结果」做成一条可配置流水线：URL 规范化去重、
robots 遵守、限速并发、HTML 解析管道、CSV/JSONL 导出，全部纯 MoonBit。

## 背景与动机

- MoonBit 生态的 HTTP 客户端、HTML 解析、robots 解析、CSV 导出等积木已就位，
  但缺少把它们串成可用采集流水线的框架层（查重见 docs/查重报告.md）。
- 数据采集是很多上层应用（数据分析、AI 语料、监控）的第一公里，
  是一个边界清晰、可验证、能体现 MoonBit 工程能力的真实需求。

## 目标用户与使用场景

- 需要批量采集公开网页数据的开发者（数据集构建、行情/舆情监控、文档同步）。
- 想用 MoonBit 做数据处理的学生/工程师，需要一个开箱即用的采集入口。

## 功能规划（10 月赛交付范围）

1. URL 层：解析、规范化（大小写/默认端口/点段/参数排序/fragment）、相对展开 ✅
2. 去重：布隆过滤器（10 万级 URL 内存可控）✅
3. Polite 抓取：robots.txt 解析缓存、限速、并发上限、超时重试
4. HTML 管道：链接提取、正文/字段提取（基于 moonbit-community/html）
5. 导出：CSV / JSONL，附一个真实站点示例（公开书籍/新闻列表页）
6. 发布：mooncakes.io 上架 `guangting0905/mooncrawl`

## 与已有工作的区别

- 不重复造轮子：复用官方 async 运行时与社区解析库，MoonCrawl 提供
  目前生态空白的「策略与调度」框架层。
- 规范化优先是本项目的核心差异点：去重失败大多源于 URL 等价形式未折叠。
