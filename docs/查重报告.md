MoonCrawl 定位为框架层（策略、调度、管道、导出），与积木库是组合关系而非竞争关系。

邻近领域均已被占用（因此放弃这些方向）：RAG 检索（MoonRetrieve、moonchunk）、
WebSocket 客户端（webmocket）、gRPC（官方 protobuf）、SQL 引擎（moonlake）、
文档转换（markitdown）、LSP（mizchi/lsp）、SSH 客户端、OAuth、向量库等。

## 结论

**MoonCrawl（网页爬虫框架）与现有 MoonBit 生态及往期参赛项目无重合。**
它复用社区积木（HTTP / HTML / robots / CSV），新增的是目前空白的框架层：
URL 规范化去重、polite 调度（robots + 限速 + 并发上限）、采集管道与结构化导出。
